AI PROJECT

AI Quiz Generator

An intelligent learning assistant that automatically parses PDF notes, generates contextual quizzes using AI, provides precise grading based on note content, and tracks wrong answers for adaptive weakness training.

Python LLM / AI PDF Parser React REST API

Key Features

📄
PDF Notes Parsing
Automatically extracts and structures content from uploaded PDF notes with bilingual display support.
🤖
AI Quiz Generation
Leverages LLM to generate relevant quiz questions strictly based on your uploaded note content.
✅
Precise Grading
AI-powered answer evaluation that checks responses against the original note content for accuracy.
🎯
Adaptive Training
Tracks incorrect answers and generates targeted practice quizzes to strengthen weak areas.
